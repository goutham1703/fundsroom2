Northstar Supply / ERP

Operations documentation.

A practical guide to the deployed manufacturing and supply workflow application: enquiry, quotation, sales order, reservation, and dispatch.

Live services

Frontend applicationBackend healthSource repository

Roles

  • ADMIN: approve quotations, confirm orders, and dispatch.
  • SALES_USER: create enquiries, quotations, customers, and view availability.
  • Administrator signup requires the configured invite code.

Demo access

  • Admin: admin@northstar.in / admin123
  • Sales: sales@northstar.in / sales123
  • New accounts require a password of at least 8 characters.

Workflow

  • Capture a customer enquiry.
  • Prepare and send a quotation.
  • Convert an accepted quotation to a sales order.
  • Confirm the order and reserve inventory.
  • Create a dispatch and reduce available stock.

Local setup

cd frontend
npm install
npm run dev

cd backend
npm install
npm start

Database

The backend includes a Prisma PostgreSQL schema. Configure DATABASE_URL, then run:

npm run prisma:generate
npm run prisma:push
npm run prisma:seed
